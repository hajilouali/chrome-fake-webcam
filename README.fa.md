# Fake Webcam — جایگزین وبکم

اکستنشن کروم که به‌جای وبکم واقعی، برای سایت‌های دلخواه یک **ویدیوی از پیش ضبط‌شده** یا یک **عکس ثابت** پخش می‌کند — با قابلیت زوم، جابجایی (pan) و پلی/پاز زنده.

## چرا این افزونه؟

بعضی سایت‌ها فقط برای ضبط یک ویدیوی کوتاه یا گرفتن یک عکس (احراز هویت، تست حضور زنده، عکس پروفایل و…) درخواست دسترسی به دوربین می‌کنند. این افزونه به شما اجازه می‌دهد به‌جای دوربین واقعی، یک ویدیو یا عکس دلخواه به آن‌ها بدهید — برای هر سایت جداگانه، با کنترل کامل روی قاب‌بندی تصویر.

## قابلیت‌ها

- **حالت ویدیو** — پخش لوپ‌شونده‌ی یک فایل ویدیویی به‌جای دوربین
- **حالت عکس** — نمایش یک عکس ثابت
- **زوم و جابجایی** — با درگ‌کردن و زوم، قاب تصویر جایگزین را تنظیم کنید؛ تغییرات حتی روی یک تماس در حال اجرا هم بلافاصله اعمال می‌شود
- **پخش / توقف** — هر لحظه که بخواهید، ویدیوی جایگزین را از همان پاپ‌آپ نوار ابزار فریز یا دوباره پخش کنید
- **صدای خودکار** — اگر فایل ویدیویی شما صدا داشته باشد، همان به‌جای میکروفون فرستاده می‌شود؛ در غیر این صورت میکروفون واقعی مثل همیشه کار می‌کند
- **کنترل جداگانه برای هر سایت** — فعال‌سازی پیش‌فرض برای همه‌جا، یا استثنا برای سایت‌های خاص از همان پاپ‌آپ
- **رابط کاربری دوزبانه** — سوییچ بین فارسی و انگلیسی در همه‌جای افزونه (پاپ‌آپ، تنظیمات، صفحه‌ی تست)
- **کاملاً محلی** — عکس/ویدیوی شما در IndexedDB خودِ مرورگر ذخیره می‌شود؛ هیچ‌چیز به هیچ‌جا آپلود نمی‌شود

## نصب (unpacked / حالت توسعه‌دهنده)

۱. این ریپازیتوری را دانلود یا `git clone` کنید.
۲. آدرس `chrome://extensions` را در کروم باز کنید.
۳. گزینه‌ی **Developer mode** (بالا سمت راست) را فعال کنید.
۴. روی **Load unpacked** بزنید و همین پوشه را انتخاب کنید.
۵. آیکون افزونه در نوار ابزار ظاهر می‌شود.

## نحوه‌ی استفاده

۱. روی آیکون افزونه کلیک کنید. از همان پاپ‌آپ می‌توانید مستقیماً:
   - یک فایل **عکس** و/یا **ویدیو** انتخاب کنید.
   - بین حالت **عکس** / **ویدیو** جابه‌جا شوید.
   - هر زمان که خواستید ویدیو را **پخش/متوقف** کنید.
   - افزونه را **به‌صورت پیش‌فرض برای همه‌ی سایت‌ها** یا فقط **برای همین سایت** فعال کنید.
۲. روی «زوم / جابجایی تصویر» در پاپ‌آپ بزنید تا صفحه‌ی تنظیمات کامل باز شود؛ در آن‌جا می‌توانید:
   - روی پیش‌نمایش زنده درگ کنید تا جابجا شود، و با اسلایدر زوم کنید.
   - لیست استثناهای هر سایت را مدیریت کنید.
۳. به سایتی که درخواست دسترسی به دوربین می‌دهد بروید — به‌جای دوربین واقعی، عکس/ویدیوی انتخابی‌تان نمایش داده می‌شود.

## تست دستی

فایل [`test.html`](test.html) یک صفحه‌ی مستقل برای تست دستی افزونه است: نشان می‌دهد افزونه روی صفحه شناسایی شده یا نه، درخواست `getUserMedia` می‌دهد، و جزئیات track/صدا را چاپ می‌کند. می‌توانید مستقیم بازش کنید (`file://.../test.html`) یا هرجایی هاستش کنید — به چیز دیگری از این ریپو وابسته نیست.

> کروم افزونه‌ها را فقط وقتی گزینه‌ی **«Allow access to file URLs»** برایشان فعال باشد (`chrome://extensions` → صفحه‌ی Details افزونه) روی صفحات `file://` تزریق می‌کند. این یک محدودیت کلی خودِ کروم است، نه چیزی خاص این افزونه.

## این افزونه چطور کار می‌کند؟

- یک content script در «دنیای اصلی» (`inject.js`) قبل از اجرای هر اسکریپت دیگری، `navigator.mediaDevices.getUserMedia` و `enumerateDevices` را بازنویسی می‌کند. وقتی ویدیو درخواست شود و افزونه برای آن سایت فعال باشد، عکس/ویدیوی انتخابی روی یک `<canvas>` رسم می‌شود (با اعمال زوم/جابجایی در هر فریم) و `canvas.captureStream()` به‌عنوان track ویدیو برگردانده می‌شود — یک `MediaStreamTrack` واقعی و معتبر که با WebRTC، ضبط و غیره کار می‌کند.
- صدا، در صورت درخواست، یا از صداپیشه‌ی خودِ فایل ویدیویی (با `HTMLMediaElement.captureStream()`) می‌آید یا از میکروفون واقعی، بسته به این‌که کدام در دسترس باشد.
- یک content script در «دنیای ایزوله» (`content-bridge.js`) بین override دنیای صفحه و تنظیمات/حافظه‌ی افزونه پل می‌زند، چون اسکریپت‌های دنیای اصلی به APIهای `chrome.*` دسترسی ندارند.
- فایل‌های رسانه‌ی شما در `IndexedDB` خودِ افزونه ذخیره می‌شوند (مستقیماً توسط صفحات popup/options، و از طریق service worker پس‌زمینه برای content script ها، چون content script ها نمی‌توانند مستقیم به حافظه‌ی افزونه دسترسی داشته باشند).

## ساختار پروژه

| فایل | نقش |
|---|---|
| `manifest.json` | تنظیمات افزونه (Manifest V3) |
| `inject.js` | اجرا در دنیای اصلی صفحه؛ override کردن `getUserMedia`/`enumerateDevices` و ساخت stream از روی canvas |
| `content-bridge.js` | پل بین `inject.js` و تنظیمات/فایل ذخیره‌شده‌ی افزونه |
| `site-key.js` | تابع مشترک برای تبدیل یک URL به یک «کلید سایت» و برچسب یکسان |
| `i18n.js` | متن‌های ترجمه‌ی فارسی/انگلیسی و توابع کمکی مشترک |
| `background.js` | Service worker؛ رساندن فایل رسانه‌ی ذخیره‌شده به content script ها |
| `media-store.js` | توابع مشترک IndexedDB (استفاده‌شده در `background.js`، `options.js`، `popup.js`) |
| `popup.html` / `popup.js` / `popup.css` | پاپ‌آپ نوار ابزار: انتخاب سریع فایل، حالت، پلی/پاز، فعال‌سازی هر سایت |
| `options.html` / `options.js` / `options.css` | صفحه‌ی تنظیمات کامل: مدیریت فایل، ویرایشگر زوم/جابجایی، لیست استثناهای سایت |
| `test.html` | صفحه‌ی تست دستی مستقل |

## محدودیت‌ها

- **فایل‌های `.mov` (QuickTime) معمولاً پخش نمی‌شوند** — این محدودیت خودِ کروم است (که عموماً از کانتینر QuickTime پشتیبانی نمی‌کند)، نه چیزی که این افزونه بتواند دورش بزند. اول فایل را به `.mp4` یا `.webm` تبدیل کنید.
- سایت‌هایی با یک Content-Security-Policy غیرمعمول سخت‌گیرانه روی `media-src` ممکن است رفتار متفاوتی داشته باشند.
- این افزونه فقط **دوربین** را جایگزین می‌کند، نه اشتراک‌گذاری صفحه (`getDisplayMedia`) یا API مربوط به `ImageCapture.takePhoto()`.

## حریم خصوصی

فایل‌های عکس/ویدیوی شما هیچ‌وقت از مرورگرتان خارج نمی‌شوند — به‌صورت محلی در IndexedDB ذخیره می‌شوند و فقط توسط همین افزونه خوانده می‌شوند. هیچ درخواست شبکه‌ای یا سرور خارجی‌ای در کار نیست.
